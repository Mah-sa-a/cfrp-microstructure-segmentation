# CFRP Microstructure Segmentation

Deep learning framework for automated segmentation of 
CFRP composite microstructures using U-Net and SAM.

## Project Structure
- `sam_segmentation/` - SAM-assisted annotation pipeline
- `synthetic_data/`   - Synthetic image generation
- `unet/`             - U-Net architecture and training
- `fine_tuning/`      - Fine-tuning on real CFRP images

## Requirements
- Python 3.x
- TensorFlow / Keras
- Segment Anything Model (SAM)
